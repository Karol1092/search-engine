# search-engine
A search engine for simple english Wikipedia articles using Term Frequency-Inverse Document Frequency (TF-IDF) and Latent Semantic Analysis (LSA) using Singular Value Decomposition (SVD).

## Installation
**Prerequisites:**
- Linux or wsl
- Python 3.12+
- 16GB+ RAM for computation
- At least few GB disk space

**Clone the repository:**
```bash
git clone https://github.com/Karol1092/search-engine.git
```
or if you are using ssh:
```bash
git clone git@github.com:Karol1092/search-engine.git
```

**Environment:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Run build script:**
```bash
python3 build.py
```

## Usage

**Start the app:**
```bash
./start.sh
```
